# financial-dashboard
Personal financial dashboard built in Python with CustomTkinter and SQLite

---

## Setup

### Installation
Make sure, Python and uv are installed.

If Python is not installed, download it from the web.

If Python is installed, but not uv, run:
```bash
pip install uv
```

### Virtual environment
Set up a virtual environment by running:
```bash
uv venv
```

After creating the `.venv/` folder, activate it:
```bash
source .venv/Scripts/activate
```

### Sync
Before running this program, run
```bash
uv sync
```
to get all the dependencies for this project.

---

## Run
Run:
```bash
uv run financial-dashboard
```
